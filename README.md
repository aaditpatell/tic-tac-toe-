# tic-tac-toe-
practicing coding so i don't forget everything i learned!! 

scanner for input, a 2D array for the board, and nested loops to handle turns and print everything out.

how it works

two players share the keyboard and take turns being X and O. On your turn you punch in a row and column (0 through 2) and it drops your mark on the board. Game keeps looping until someone gets three in a row or the board fills up and it's a tie.

running it

javac TicTacToe.java java TicTacToe
